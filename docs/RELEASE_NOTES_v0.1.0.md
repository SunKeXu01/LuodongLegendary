# 泺栋传奇 v0.1.0

首个 Windows 离线试玩版本。

## 内容

- 云津渡“护送百姓 / 追查证据”开局选择。
- 青冥剑式、伏虎掌、机弩术三门武学。
- 寒岭门客、黑衣暗桩、寂音武僧三段战斗。
- 碎银、随机兵器和自动装备成长。
- 版本化本地离线存档。

## 技术

- Electron Windows x64 portable 客户端。
- 从 Unlicense 项目 `JevLOMCN/mir1` 迁移的通用地图 Cell、可行走缓存、安全区、实体阻挡和移动校验结构。
- GitHub Actions 自动测试、构建 Windows `.exe` 并发布 Release。

## 已知限制

- 当前地图规则已完成，但可视化探索尚未接入首版界面。
- 暂无音乐、正式美术、按键移动和完整副本。
- Windows 构建未签名，系统可能显示未知发布者提示。
