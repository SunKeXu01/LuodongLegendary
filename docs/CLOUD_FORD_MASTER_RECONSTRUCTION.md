# 云津渡场景母图重建清单

视觉母版：`art/concepts/cloud-ford-master-environment-v1.png`

母图负责决定风格与空间关系，游戏地图必须重新建立可行走网格、碰撞、遮挡、
任务点和室内入口。不能直接把整张图铺在地面上冒充可玩场景。

## 空间骨架

| 区域 | Tiled 范围 | 玩法职责 |
| --- | --- | --- |
| 南市入口 | `x 18–28 / y 34–47` | 玩家出生、教学与第一批商贩 |
| 中央商市 | `x 15–31 / y 26–35` | 客栈、铁铺、货栈、任务 NPC |
| 云津横街 | `x 8–39 / y 20–23` | 横向主路、桥渡与河岸连接 |
| 北门商路 | `x 21–25 / y 0–26` | 追兵战、北门和远景山道 |
| 云津河 | `x 34–47` | 水面、船只、渡口和不可行走区 |
| 石桥与木栈 | `x 34–41 / y 20–23` | 唯一常规过河通道 |

## 建筑优先级

1. 临河客栈：两层白墙青瓦，沿江露台，是地图主视觉锚点；
2. 鲁氏铁铺：开放式锻炉、暖色火光，是装备淬炼入口；
3. 云津货栈：大屋檐与货箱院落，承载镖银支线；
4. 听雨茶亭：轻量半开放建筑，承担休整和江湖传闻；
5. 北门行栈：连接追兵战与北门商路；
6. 石桥、木栈与泊船：建立江河交通身份。

每栋建筑分为 `下层/屋顶/门窗与招牌/交互碰撞` 四部分。屋顶必须能在
玩家进入遮挡区时淡出，下层继续参与足底 Y 排序。

## 视觉拆解

- 地面：泥土、湿石路、市场铺装、水面；
- 低层物件：摊位、货箱、车、石栏、矮墙；
- 高层遮挡：屋顶、树冠、牌坊横梁；
- 动态层：水纹、旗帜、炉火、灯笼、雨丝；
- 远景层：北门、山道、山体、雾；
- 人物层：主角、巡检、商贩、铁匠、追兵；
- UI 层：位置、任务、目标、技能、交互反馈。

## 建模取舍

建筑可先用低模 3D 搭建统一透视，再从固定 45° 镜头渲染为 2D 分层 PNG；
人物继续使用八方向手绘精灵。桥梁、牌坊和大型屋檐适合采用这种
“3D 定形—2D 输出”流程，能减少手绘透视漂移，同时保留传统 2.5D 的运行
成本和遮挡逻辑。
