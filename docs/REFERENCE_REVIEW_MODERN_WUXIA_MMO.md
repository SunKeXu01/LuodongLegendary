## v0.5 客户端体验目标

- 左键点击地面移动，点击敌人锁定、自动接近并攻击。
- 任务面板提供“追踪”按钮，一键选择最近任务目标并自动寻路。
- 战斗信息采用角色框、目标框、世界名牌、浮动伤害和武学栏多层反馈。
- HUD 使用低遮挡的墨黑半透明面板、玉色与鎏金强调色，保留场景可见面积。
- 预留角色、背包、武学、任务和社交入口，尚未完成的系统给出明确提示。

## 后续联网边界

客户端输入先转为“移动、选中、施放、交互”等玩家意图；离线模式由本地规则处理，
联网模式再由网络适配器发送给权威服务端。服务端负责角色数值、掉落、任务与交易
结算，客户端只负责输入、预测和表现。这一边界可避免未来联网时重写整个 HUD。
