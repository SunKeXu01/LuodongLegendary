# 泺栋传奇 v0.10.0

这一版根据经典国产武侠页游的视觉共性，集中优化人物头像、网游 HUD 和
云津渡地图层次。

## 主要变化

- 新增独立 SubViewport 实时 3D 少侠头像；
- 修复头像视口继承主地图、混入建筑背景的问题；
- HUD 面板加入统一鎏金角饰、细边框和投影；
- 新增动态起伏和双层波纹的云津河面 Shader；
- 商路新增 39 块错落青石；
- 河岸新增 18 组缩放、旋转和色彩不同的自然石；
- 六个方盒远山替换为七座多面山体和半透明山岚；
- 环境重新调整曝光、对比度、饱和度、日光和环境光；
- 扩展自动回归，覆盖水体材质、山岚、青石路、河岸和 3D 头像。

## 实机验证

Godot 4.7.1 客户端已实际启动检查普通窗口和放大窗口。角色、河面、道路、
河岸、HUD 和头像均正常显示，未出现黑屏；头像现在使用独立 3D 世界，能够
显示少侠头部、上身与长衫，不再混入主地图建筑。
