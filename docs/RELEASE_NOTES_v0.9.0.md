# 泺栋传奇 v0.9.0

这一版完成成熟比例角色、骨骼动作和第一层武侠换装底座。

## 主要变化

- 移植公版 `Cats-Godot4-Modular-Souls-like-Template` 男女角色；
- 接入包含 121 套动作的共享人形动画库；
- 玩家、NPC、敌人与首领统一使用成熟比例骨骼；
- 加入待机、行走、奔跑、挥砍、突刺、受击和倒地动作映射；
- 在骨骼上增加交领长衫、下裳、腰带、广袖、袖口与右手佩刀；
- 玩家和居民隐藏西式铠甲模块，敌人保留护甲用于阵营识别；
- 增加角色来源、许可证、固定提交和文件哈希记录；
- 扩展自动回归，防止角色意外退回卡通模型或丢失关键动作。

## 实机验证

Godot 4.7.1 客户端已实际启动验证：场景正常显示，角色不是 T 姿势，人物
比例与头顶 UI 可用，纯鼠标点地移动、点敌选中、自动接战及扣血流程正常。

角色身体、骨骼和动作接口已稳定，但当前服装仍是第一版模块化武侠轮廓，
后续会在不重做控制与战斗的前提下替换为更精细的明代衣装网格。
