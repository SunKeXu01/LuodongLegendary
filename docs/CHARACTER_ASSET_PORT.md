# 成熟比例角色与动作移植

## 目标

`v0.9.0` 解决旧版 KayKit 角色比例过度卡通、动作表现像原型验证的问题。
角色层仍保持单机、纯鼠标操作和现有战斗规则不变，只替换可复用的身体、
骨骼、动作与换装技术底座。

## Godot 集成

两个 GLB 保留上游 Godot humanoid 骨骼映射。导入时把原始骨骼统一重定向
为 Godot 人形骨骼名称，随后由玩家、NPC、普通敌人和首领共享 121 套动作。
当前正式映射至少覆盖：

- 待机：`LightIdle`
- 行走/奔跑：`LightWalking`、`LightRunning`
- 刀剑攻击：`Slash1`、`Slash2`、`Stab1`
- 受击：`Hurt1`、`Hurt2`
- 倒地：`Die1`

## 武侠外观层

基础人形不是最终明代服装。客户端在角色骨骼上增加可替换的模块化外观：

- 胸骨：交领长衫和衣襟；
- 髋骨：下裳与腰带；
- 左右上臂、前臂：广袖与袖口；
- 右手：跟随近战动作旋转的佩刀；
- 身份配色：青冥门、渡口居民、寒岭武人和首领使用不同布料色。

玩家和居民隐藏上游西式铠甲、头盔模块；敌人暂时保留护甲用于战斗识别。
该层让现阶段画面先具备明确武侠轮廓，也为后续换入高精度明代衣装网格
保留稳定的骨骼、动作和角色接口。

## 验证

自动玩法回归会检查：

- 正式场景必须使用新的成熟比例人形，而不是 KayKit 回退模型；
- 待机、奔跑、挥砍动作必须存在；
- 玩家必须隐藏西式铠甲、头盔并生成长衫、下裳和佩刀；
- 敌人必须保留可识别的护甲模块；
- 原有鼠标选敌、自动寻路、战斗、掉落和 UI 状态继续工作。

此外使用 Godot 4.7.1 实际启动客户端检查了人物朝向、站立姿势、角色比例、
头顶信息与纯鼠标接战流程；未出现黑屏或 T 姿势。
