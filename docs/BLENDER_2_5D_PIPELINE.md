# Blender 3D 定形与 2.5D 输出流程

《泺栋传奇》使用 Blender 5.2 LTS 统一建筑和人物的比例、透视与动画，再按
需要输出为 Godot 直接使用的 GLB 或传统 2.5D 透明 PNG。

## 为什么采用双输出

- 宏大场景母图可以决定美术方向，但无法提供碰撞和寻路；
- 纯手绘大量斜向建筑容易产生透视漂移；
- 低模 3D 能稳定保持 45° 镜头、门窗尺寸、屋顶结构和受光方向；
- 同一模型既能用于实时 3D，也能批量渲染成低运行成本的 2.5D 分层图；
- 屋顶和下层独立输出后，Godot 可以在玩家进入室内时淡出屋顶。

## 已否决的低模验证稿

早期 `tools/blender/build_riverside_inn.py` 只用于验证固定相机、占地、透明
背景和遮挡分层。它依赖基础几何体拼装，未达到正式美术品质，不能作为游戏
建筑模板，也不再进入运行场景或发布包。

当前临河客栈使用高清手绘透明图：

- `art/source/imagegen/riverside_inn-painted-chroma-v1.png`：保留的生成源图；
- `godot/assets/isometric/buildings/riverside_inn-painted-v1.png`：去色键后
  的游戏资产。

## ACA 筑韵古建生产线

正式古建采用 [ACA Builder](https://github.com/willimxp/ACA-Builder) 0.6.6
与 Blender 5.2 生产。插件只安装在美术工作机，不随游戏、源码仓库或安装包
分发；正式商业发布前按作者条款完成商用备案。

首批正式模块：

- 县城城门洞与青砖台基；
- 上层歇山城楼；
- 左右直城墙段与雉堞；
- 城墙转角、台阶、旗杆和石狮；
- 下层碰撞图、屋顶遮挡图和完整预览图。

所有模块使用同一正交相机、左上主光和透明画布。建筑下层、檐口屋顶和
地面阴影分别渲染，三张图保持相同分辨率、坐标和足底锚点。

## 建筑批量派生

铁铺、货栈、茶亭与民居共享：

- 台基高度、柱径、楼层高度和门窗模数；
- 青瓦、白墙、深木、窗纸、朱砂和旧铜材质；
- 固定正交 45° 相机；
- 下层、屋顶、预览和 GLB 导出逻辑。

每栋建筑只修改占地、层数、屋顶类型、开间和功能性部件，避免重复搭建。

## 人物流程

1. 按概念稿创建成年人体和明代交领长衫；
2. 建立根骨、骨盆、脊柱、头、四肢和武器挂点；
3. 制作待机、行走、攻击、受击和死亡动作；
4. 固定相机每 45° 旋转一次，输出八方向动画；
5. 所有帧落在 `160×240` 画布和同一足底锚点；
6. Godot 使用 `AnimatedSprite2D` 播放，武器和阴影可独立分层。

## 验收

- Blender 脚本能在无界面模式重建全部输出；
- GLB 可由 Godot 导入并实例化；
- PNG 保留 Alpha 通道；
- 下层与屋顶像素对齐；
- Tiled 占地与模型真实占地一致；
- 角色能够绕开建筑，进入遮挡区时屋顶平滑淡出。
