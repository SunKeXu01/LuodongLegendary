# 泺栋传奇 v0.11.0

这一版把玩家进入游戏前后的身份表现连成完整流程，并用可追溯的 CC0 PBR
材质提升云津渡地表质感。

## 主要变化

- 新增水墨暗金风格的启动与角色创建界面；
- 支持输入最多八个字符的原创角色名；
- 新增青冥门、沧浪门、锦衣行三种原创江湖出身；
- 角色预览、场景人物和实时头像会随出身切换青、蓝、绛三种服色；
- 姓名和出身会同步显示在网游式 HUD 与角色详情面板；
- 创建完成即写入离线存档，再次启动可继续已有角色；
- 云津渡地面接入 Poly Haven `Mud Forest` 1K PBR 材质；
- 商道和抬高青石接入 Poly Haven `Grassy Cobblestone` 1K PBR 材质；
- PBR 材质使用漫反射、OpenGL 法线与 ARM 通道贴图；
- 补充素材作者、CC0 许可、源地址、文件清单和 SHA-256 校验值；
- 扩展自动回归，覆盖 PBR 地形、角色资料存档、创建界面与外观切换。

## 实机验证

Godot 4.7.1 客户端已验证角色创建、三种出身切换、确认入场、实时头像和
云津渡地图渲染。地面和道路拥有可辨识的泥土、落叶、苔草、石缝和湿润
粗糙度层次，创建界面关闭后可继续进行纯鼠标移动、交谈和战斗。

## 第三方素材

本版本只新增 Poly Haven 的 CC0 地表纹理，没有引入任何商业武侠 IP 的
人物、地图、界面或剧情素材。完整来源与校验值见
`godot/assets/vendor/poly_haven/SOURCE.md`、`SHA256SUMS` 和项目根目录
`THIRD_PARTY_NOTICES.md`。
