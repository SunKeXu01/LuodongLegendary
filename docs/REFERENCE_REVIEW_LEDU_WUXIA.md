# 乐都网经典武侠页游参考拆解

参考页面：
<https://www.ledu.com/clx/wiki/wiki60.html>

该页面是十款经典国产武侠页游的汇总，不是可以整体移植的开源游戏。项目
只提取通用的视觉语言和玩法结构，不使用页面所列游戏的角色、名称、剧情、
美术或商标。

## 可落地的共性

- 写实比例人物和清楚的门派身份；
- 青、黑、褐、金构成的沉稳武侠主色；
- 江南水乡、山岭、寺院等分层山水场景；
- 角色、建筑和道路使用接近现实的比例；
- 技能招式具有明确刀光、命中和受击反馈；
- 基础操作简单，养成信息长期可见；
- 任务、角色、武学、背包和社交入口集中在网游式 HUD。

## v0.10.0 对应实现

### 人物

- 继续使用公版成熟比例人形和 121 套共享动作；
- HUD 头像从“侠”字占位改为独立 3D 世界实时渲染的少侠模型；
- 头像与世界人物共享长衫、骨骼和阵营配色。

### 界面

- 保留纯鼠标技能栏、目标框、任务追踪和小地图；
- 所有主要面板统一加入细金边、鎏金角饰和投影；
- 状态框继续显示气血、内力、境界和人物身份。

### 地图

- 原平面河道替换为细分 PlaneMesh 和动态空间水体 Shader；
- 商路增加错落青石，河岸增加缩放、旋转各异的自然石带；
- 方盒远山替换为多面山体，并加入独立半透明山岚层；
- 全局调色转为低饱和青灰褐金，降低过曝和塑料感；
- 保留已经移植的 Polygonal Mind CC0 东亚建筑模块。

## 后续方向

后续仍需逐步补充更精细的明代服装网格、植被与地表 PBR 贴图、更多城镇
街区、室内场景和角色创建界面。当前版本先建立可以持续替换资产而不重做
战斗、导航和 UI 的稳定渲染结构。
