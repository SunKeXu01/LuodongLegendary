# 《泺栋传奇》产品方向 v0.2

## 定位

一款以明中叶江湖为舞台的复古武侠单机 ARPG，首发形态为 Windows 离线客户端。玩家以青冥门新入门弟子的身份游历湖广，在云津渡的商埠纷争、寒岭武氏的旧怨和寂音禅院的暗局之间作出选择。

## 核心循环

探索区域 → 接取主线 / 副本 / 支线 / 奇遇 → 招式战斗与机关解谜 → 获取兵器和碎银 → 提升武学与声望 → 推进云津渡故事。

## 首个垂直切片

1. 在云津渡选择护送百姓或追查械斗证据。
2. 使用青冥剑式、伏虎掌或机弩术击败寒岭门客。
3. 获得更强的兵器并进入寒岭暗局。
4. 以寂音禅院作为第一个大型副本入口。

## 时代与世界规则

- 背景为嘉靖至万历年间的架空湖广江湖。
- 朝堂势力采用锦衣卫、布政使、按察司、卫所和地方乡族等明代框架。
- 冲突来自渡口商埠、宗族旧怨、师门纷争、镖银和官商利益，不采用清末湘军或巡抚制度。
- 武学以内功、点穴、奇门、毒术和机关为主；稀有秘术保持克制，不以飞剑仙术作为常规战斗方式。

## 内容边界

只使用“地方势力冲突、寺院暗局、庄园突围、旧案追查”等通用叙事模板。全部人物、势力、地名、任务、台词、数值、地图、美术、音效与代码均为原创，不使用任何外部作品的专有名称或内容。
