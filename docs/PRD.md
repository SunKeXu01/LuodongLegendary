# 《泺栋传奇》产品需求文档

> 版本：v0.2 · 平台：Windows 离线单机 · 类型：复古明朝武侠 ARPG · 阶段：垂直切片开发

## 1. 产品概述

《泺栋传奇》是一款明中叶架空江湖题材的单机武侠游戏。玩家扮演寻师入门的少年，在湖广云津渡卷入两县大族、青冥门和寒岭武氏的多年纷争，并逐步探查寂音禅院、武家庄和江湖旧案。

核心体验是“游历—选择—战斗/机关—兵器成长—推进故事”。首个版本不包含登录、联网、多人、排行榜、广告或付费系统。

## 2. 内容结构

| 类型 | 内容 | 作用 |
| --- | --- | --- |
| 主线 | 离乡问道、云津渡风波、寒岭暗局、旧债新裁 | 承担长线选择与势力关系 |
| 大型副本 | 寂音禅院、寒岭武庄突围 | 承担潜入、机关、连续守关与关键战斗 |
| 城镇支线 | 断义旧案、孤剑客的旧伤、失镖疑云 | 提供独立选择和武学/装备奖励 |
| 野外奇遇 | 街边高人、云水夜盗、乡集擂台、山药救亲、道观风波 | 提供短时探索与随机反馈 |

剧情单元必须保持可独立组合；主线决定章节推进，大副本提供关键节点，支线与奇遇不应阻塞主线完成。

## 3. 武侠与历史框架

- 时间：架空明中叶，参考嘉靖至万历的官制和社会结构。
- 朝堂：锦衣卫、布政使、按察司、卫所和地方乡族。
- 江湖：门派松散，地方武馆、家族武师、镖师、水匪、猎户和游方术士共同构成生态。
- 武学：内功、拳掌、剑术、点穴、奇门、毒术和机关；超自然效果仅作为罕见秘术。

## 4. MVP 玩法

1. 三门开局武学：青冥剑式、伏虎掌、机弩术。
2. 云津渡两条初始抉择：护送百姓或追查证据，影响渡口声望和后续文本。
3. 三场连续战斗：寒岭门客、黑衣暗桩、寂音武僧。
4. 掉落碎银与兵器，自动装备攻击更高的兵器。
5. 本地存档、重新开始与离线游玩。

## 5. 合规与版权边界

- 仅使用通用冲突模板，不复制任何外部文学、影视或游戏的角色、门派、地名、情节文本、地图、美术、音乐与数值。
- 不使用清末专属制度或名称；历史元素仅作为明代架空背景参考。
- 所有第三方代码和素材必须记录来源、版本与许可证，见 `THIRD_PARTY_NOTICES.md`。

## 6. 验收标准

- 断网环境中可完整进行垂直切片并保持本地进度。
- 选择、战斗、掉落和兵器提升结果确定、可测试且可重放。
- 主线、副本、支线、奇遇的内容配置互相独立。
- 不含外部作品专有名称、素材或未经授权的内容。
