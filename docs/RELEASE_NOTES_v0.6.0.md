# 泺栋传奇 v0.6.0

这一版继续把原型推进为现代 2.5D 武侠网游观感的 Windows 单机客户端。

## 新增

- 云津渡加入原创临水茶亭：石台、朱红木柱、明式歇山顶、金色檐饰、
  正脊和“云津茶亭”匾额。
- 目标框加入敌方印记、气血与状态信息。
- 五格武学栏加入武学印记、名称、内力消耗、纵向冷却遮罩和倒计时。
- 排队武学自动接近射程时显示“候招”进度条。
- 首领蓄力“震钟劲”时显示危险施法条。

## 技术迁移与许可

- HUD 的组件职责参考 MIT 项目 `Relintai/broken_seals` 的 unit frame、
  action slot、cooldown wipe 与 cast bar 分层。
- 所有布局、绘制、状态和交互均按《泺栋传奇》的纯鼠标单机战斗重新实现；
  未复制上游素材、界面皮肤、地图或世界观。
- `jynew` 的许可不允许直接复制其代码或资源，因此本项目没有移植其内容。

## 验证

- Godot 4.7.1 脚本解析通过。
- 游戏状态与场景冒烟测试通过，并覆盖茶亭、冷却遮罩、候招条和首领施法条。
- 在 macOS 上实际启动 Godot 客户端，检查了日间、细雨、镜头移动和战斗画面。
