# 泺栋传奇 v0.8.0

本版继续把云津渡从通用 3D 原型收敛为明朝武侠 2.5D 场景，重点替换最后
两处明显的欧洲建筑轮廓，并升级近战武学反馈。

## 场景

- 鲁氏铁铺不再实例化 KayKit 欧洲铁匠铺，改由 Polygonal Mind CC0
  青瓦歇山顶、红墙、朱柱、木梁和石阶重新组合。
- 铁铺新增中文匾额、金属锻炉、发光炭火和局部暖光。
- 云津货栈不再实例化 KayKit 欧洲市场建筑，改用真实东亚建筑模块，并新增
  中文匾额和檐下灯笼。
- 两座新建筑继续接入原有导航阻挡和镜头遮挡淡化。
- 本机 Godot 4.7.1 .NET 实机截图：
  `docs/screenshots/cloud-ford-v0.8.0-preview.jpeg`。

## 战斗

- 从 JohanAR 更新、Oussama BOUKHELF 原作的 MIT Trail3D 技术迁移并
  重构相机朝向三角带拖尾。
- 青冥剑式、伏虎掌和敌人反击会生成带宽度与寿命衰减的弧形刀光。
- 机弩术保留直线曳光，近战与远程在斜俯视镜头下具有不同的视觉语义。
- 新拖尾使用有界采样并在效果结束后主动释放节点。
