# 泺栋传奇 v0.4.0

这是客户端从网页原型迁移到 Godot 原生游戏框架的第一版。

## 核心变化

- 使用 Godot 4.7.1 重建 Windows 客户端
- 使用原创非像素 2.5D 明朝武侠场景“云津渡”
- 全面改为纯鼠标操作：点击地面移动、点击敌人选中
- 选中敌人后自动追击、进入攻击距离后自动施展武学
- 提供青冥剑式、伏虎掌和机弩术三种可点击武学
- 重做网游式角色状态、目标、任务、货币、消息和技能栏
- 使用 Godot `NavigationAgent2D`，为后续大型地图和 NPC 寻路打基础

## Windows 安装

- 产物改为 `LuodongLegendary-0.4.0-win-x64-setup.exe`
- Inno Setup 安装向导允许玩家指定安装目录
- 使用 LZMA2 Ultra64 与固实压缩减少下载体积
- 支持创建桌面快捷方式和完整卸载
- 客户端仍为无需联网的单机游戏
