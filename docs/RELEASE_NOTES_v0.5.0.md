# 泺栋传奇 v0.5.0

## 2.5D 视觉重构

- 移植 Godot 等距 3D 镜头结构，加入正交投影、阻尼跟随、滚轮缩放、
  战斗震屏与建筑遮挡淡化
- 引入 KayKit CC0 模块化村镇资产，重建云津渡客栈、民居、铁匠铺、
  货栈、摊位、植被与环境道具
- 玩家、NPC、敌人和首领改用带骨骼的 GLB 角色模型，并接入待机、跑步、
  攻击、受击和倒地动作
- 增加 3D 世界任务标识、敌人境界/气血条、掉落光柱和茶棚交互点
- 完成实机调色和名牌密度修正，保留纯鼠标移动、选敌、交谈和技能操作

## 工程与发行

- 新增第三方资产固定提交、许可证和移植边界文档
- 只保留地图实际使用的环境模型，环境包由 4.6 MB 精简到约 700 KB
- 扩充玩法烟测，验证外部建筑、骨骼角色、镜头、交互、锻造、任务与副本
- Windows 安装包继续采用 LZMA2 压缩并允许用户选择安装目录
