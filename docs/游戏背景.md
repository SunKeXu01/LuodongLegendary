# 《江湖奇侠传》剧情拆分清单【移植明朝背景｜游戏专用】

适配：**明中叶（嘉靖/万历）江湖，朝堂有锦衣卫、地方乡绅林立**
法律安全准则先重申：

1. 只取用**故事骨架、冲突模板**；**全部人名、门派名、地名重新改名**，禁止直接照搬原著名称；
2. 删掉清末专属元素（湘军、巡抚体制），替换明代官制（布政使、按察使、锦衣卫、卫所、乡族械斗）；
3. 偏仙侠的飞剑白光可弱化，调整为内功、奇门、点穴、机关，做成传统武侠；
4. 单元故事互相独立，主线、大副本、支线、奇遇严格划分，可以自由挑选组合。

## 一、主线剧情（玩家主线完整长线，可作为游戏核心流程）

### 主线原型：赵家坪两县宗族械斗 + 两大武林派系对峙

原著：平江、浏阳争赵家坪，昆仑派、崆峒派门人各自助阵，矛盾层层激化。
**明朝改版设定参考**

- 背景：湖广两县争夺渡口商埠，地方大族世代结仇，双方重金招揽江湖武人助拳；
- 门派魔改（不要直接昆仑、崆峒）
  原著昆仑 → 【青冥门】（崇尚侠义，门下多隐士剑客）
  原著崆峒甘家 → 【寒岭武家】（地方豪强世家，行事善恶混杂）
- 主角原型：柳迟（童子寻师）
  玩家开局模板：
  少年酷爱武学，不愿埋首诗书，伪装游方乞丐寻访名师，机缘拜入青冥门门主门下，被迫卷入渡口宗族纷争，逐步揭开两大派系数十年旧怨。

主线阶段划分：

1. 序章：少年离家，一路游历，偶遇各路江湖客（串联小型奇遇支线）
2. 上篇：渡口械斗频发，各派高手陆续登场，小规模江湖厮杀
3. 中篇：寒岭武家动用阴毒手段，掳人、设陷阱，冲突升级
4. 下篇：幕后陈年恩怨浮出水面，玩家需要选择调解矛盾或是武力了结纷争

> 适配类型：开放世界武侠 / ARPG主线，自由度高，可以中途介入各类支线。

## 二、大型副本（独立地下城，可做多人副本/主线关键大关）

### 副本1：古禅秘窟（原型：火烧红莲寺｜最高价值副本）

原著梗概：红莲寺表面清修，实则贼巢；住持伪善，地牢囚禁女子、客商，官员暗访被擒，扣于铜钟之下；少年旅客撞破秘密，各路侠客联手围剿，最终寺院焚毁。
明朝移植改造：
寺院更名【寂音禅院】，坐落深山要道。住持外显高僧风范，暗中劫掠商旅、私藏重犯，地牢密布机关。
**副本流程设计**

1. 支线触发：路人求助，亲人前往禅院之后杳无音信；
2. 潜入阶段：夜探寺院，偷听僧众密语，发现地牢入口；
3. 危机事件：一名布政使暗访被困巨铜钟内，限时救援；
4. BOSS战：伪善住持，辅以多名武僧、机关陷阱；
5. 结局分支：全歼恶僧 / 放走愿意弃恶从善的僧人 / 拿到寺院藏宝后抽身离去。

玩法亮点：潜行、地牢探索、机关解谜、多结局，武侠游戏经典寺庙副本模板。

### 副本2：武府突围战（原型：桂武夜闯甘家）

原著梗概：青年男子入赘敌对武人家族，婚后发现家族作恶，决心带着妻子连夜逃亡，接连闯过十几重高手关卡。
明朝移植改造：
寒岭武家庄，庄内层层院落、布设哨卡。
剧情：主角友人入赘武家，知晓家族阴谋，决意携妻出逃；玩家可选择暗中相助。
战斗形式：**连续闯关模式**，一关一名守关高手，越往里战力越强。
适合做成：线性闯关副本、竞技场剧情关卡。

## 三、中型支线任务（城镇支线、帮会委托，玩家随时可接）

### 支线A：侠客沉冤（原型：张汶祥刺马）

原著原型：异姓兄弟，一人身居高位背弃盟约，构陷同伴；幸存者隐忍多年，千里寻仇当众刺杀高官。
明朝适配：
三名侠客早年结义，其中一人投靠官场，为仕途出卖兄弟；幸存者隐姓埋名苦练武艺，伺机复仇。
分支选项：
①协助侠客完成复仇（江湖路线，得罪官府）
②劝说侠客走官府诉状之路（官府路线，和江湖侠客产生隔阂）
③从中调解，寻找当年真相，发现背后另有幕后推手。
⚠️规避：不要直接使用“刺马案”名称，淡化真实历史原型痕迹。

### 支线B：女剑仙往事（原型：红姑个人故事）

原著梗概：红姑身世凄苦，身负血海深仇，辗转拜师，行走江湖斩除恶人，性格外冷内热。
玩法：游历途中偶遇独行女剑客，逐步解锁她的过往回忆任务链；
奖励：独门轻身功法、特殊饰品。

### 支线C：镖银失窃谜案

原型原著支线：走镖队伍途中遭劫，江湖传言是某门派所为，引发两派冲突，真相另有隐情。
任务：受镖局委托追查失镖，多方打探，发现盗镖者并非传闻门派，是第三方势力有意挑拨武林矛盾。

## 四、小型随机奇遇（野外触发、开放世界偶遇，几十分钟可完成）

1. **乞丐藏艺**
   路边疯癫乞丐，言语疯癫，实则隐世高手；答对谜题/出手相助，可以指点一招武学。（原型柳迟遇侠桥段）
2. **湘江夜盗**
   商船夜行，遭遇水匪劫掠，可选择出手相助、坐视不理、与水匪谈判。
3. **擂台赌武**
   乡镇设下比武擂台，背后有人设局出千，揭穿黑幕或参与赌赛。
4. **寻药救亲**
   江湖客四处寻访稀有药材，山中毒虫猛兽看守药草；可帮忙采药，换取秘籍情报。
5. **道观风波**
   小道观师徒反目，弟子觊觎师门秘传，玩家介入调解或出手平乱。

## 五、世界观可直接取用的设定（明朝武侠适配）

1. 江湖生态：没有一统武林的盟主，门派松散，乡绅、宗族势力极大，很多江湖高手依附地方大族；
2. 冲突来源：不止正邪大战，更多是**地界争夺、商业利益、世代私仇、师门恩怨**，更贴近底层江湖；
3. 势力分层
   - 顶层：隐世大宗高手，极少出世；
   - 中层：各地武馆、家族武师、独行剑客；
   - 底层：镖师、水匪、猎户、游方术士、走江湖卖艺之人；
4. 势力与朝堂关系：明朝厂卫偶尔渗透江湖，招募侠客充当密探；江湖人大多忌惮官府，尽量避免和朝廷正面冲突。

# 六、落地开发重要修改清单（避版权风险，必看）

1. 地名修改
   红莲寺 → 寂音禅院
   赵家坪渡口 → 云津渡
2. 门派修改
   昆仑派 → 青冥门
   崆峒甘家 → 寒岭武氏
3. 人物全部原创名称，**严禁柳迟、吕宣良、红姑、桂武、甘联珠、知圆和尚这些名字**
4. 时代元素替换
   清朝巡抚 → 明代布政使、按察佥事
   湘军、清末团练 → 地方乡勇、卫所士兵
5. 超自然内容取舍
   原著飞剑、五鬼搬运可以保留为稀有秘术，或者简化为奇门机关、毒术，做成偏写实武侠。
