# 泺栋传奇 v0.2.0

首个带实时游戏画面的 Windows 离线试玩版本。

## 新增内容

- 使用 Phaser 3 重建云津渡俯视角游戏场景。
- 可见的河流、木桥、石径、客栈、药铺、树木、人物和敌人。
- `WASD` / 方向键移动，空格 / `J` 实时出招。
- 敌人视野、追击、碰撞和近身反击。
- 青冥剑式、伏虎掌、机弩术三种攻击范围和伤害。
- 攻击弧光、受击闪烁、镜头震动和伤害飘字。
- 敌人死亡和碎银掉落拾取。
- 游戏 HUD、任务追踪、剧情选择和重新开始。

## 开源技术迁移

- Phaser 场景、Arcade Physics 移动碰撞和镜头结构参考
  `remarkablegames/phaser-rpg` 固定提交
  `46d12970317baf0875e646efced1eeca59471c0b`，许可证 MIT。
- 未复制上游示例地图、人物、图块或其他美术素材。
- 全部地图画面、角色造型、名称和明代武侠内容均为本项目原创。

## 已知限制

- 当前为程序绘制的临时像素美术，后续将替换为正式原创素材。
- 暂无音乐、完整对话树和大型副本。
- Windows 构建未签名，系统可能显示未知发布者提示。
