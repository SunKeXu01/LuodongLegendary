# 东亚建筑资产移植记录

## 目标

`v0.7.0` 不再把“中式地图”理解为程序化方块换颜色，而是将许可证清晰、
可再分发的真实开源 3D 模型引入 Godot，再按云津渡的导航、镜头和剧情重新
组合。

## 选定上游

- 仓库：`ToxSam/cc0-models-Polygonal-Mind`
- 固定提交：`56db2d4088512531a070d0bf3eb9d284d077528d`
- 原作者：Polygonal Mind
- 许可证：CC0 1.0 Universal
- 使用集合：`tomb-chaser-2`、`lunar-year`

上游提供的是独立 GLB 模块，不移植其地图、玩法、霓虹广告、人物或世界观。
项目只保留墙、柱、梁、屋顶、石阶、灯笼、牌坊和灯阁等技术美术资产。

## Godot 重构

`CloudFordWorld3D` 将模型重新组合成：

- 临河客栈：四面红墙、四根朱柱、额枋、青瓦歇山角顶、门楼、石阶、
  双灯和中文匾额。
- 渡口民居：缩小比例的四合外墙、直坡青瓦屋顶、朱柱、石阶和门楼。
- 云津渡木牌坊：替换原先三块程序化长方体。
- 云津巡夜灯阁：作为街市视线地标。

建筑继续参与原有的正交 2.5D 镜头遮挡淡化与导航网格阻挡，不是仅供截图
使用的背景模型。客栈双灯接入世界时辰系统，夜间自动亮起。

## 纹理处理

上游 GLB 内嵌 PNG。Godot 4.7 的默认导入器会按
`<模型名>_<内嵌图片名>.png` 外置纹理。为避免全新 Windows 构建出现外部
纹理路径警告，本项目从 GLB bufferView 原样提取这些 PNG 并与模型一同提交；
没有重新绘制或生成纹理。

## 验证

- 从空的 GLB 导入元数据重新导入，Godot 编辑器无 ERROR/WARNING。
- 游戏状态测试断言客栈与民居包含真实导入屋顶，并断言牌坊、灯阁存在。
- 实际启动游戏，在日间、细雨、镜头跟随与纯鼠标导航状态下检查建筑比例。
