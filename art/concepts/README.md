# 原创角色概念稿

`hero-qinghui-turnaround-v1.png` 是《泺栋传奇》手绘 2.5D 视觉迁移的第一张
原创角色母版。它用于固定青灰长衫剑客的身份、轮廓、服装结构、配色和四个
斜向观察角度，不直接作为游戏精灵动画。

概念稿由 OpenAI 内置图像生成工具生成，提示约束包括：

- 明代架空武侠青年剑客；
- 同一人物的前左、前右、后左、后右四个等轴测视图；
- 束发、木簪、窄披肩、青灰交领长衫、深色腰封和一柄长剑；
- 手绘水墨与水粉质感，大色块、清晰轮廓、非像素风；
- 不使用任何现有武侠 IP 的人物、门派、标志、文字或场景。

正式资源需要在 Krita 中重新拆分结构、校正各方向透视、统一足底锚点，并按
`docs/ISOMETRIC_2D_ART_SPEC.md` 制作八方向动画和透明 PNG 图集。
